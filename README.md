***ATM Simulation System • Python***



**Project Overview**



This project is a console-based ATM Simulation System developed using Python. It simulates ATM operations such as PIN login, balance enquiry, cash deposit, cash withdrawal, transaction history, and exit functionality.



**Tools used**

Jupyter Notebook



**Features**



\-Secure PIN authentication

\-Balance enquiry

\-Deposit and withdrawal operations

\-Transaction history tracking

\-Invalid input handling

\-Menu-driven user interface



**Workflow**



1\. User enters a PIN for authentication.

2\. The ATM menu is displayed.

3\. The user can check balance, deposit money, withdraw money, or view transaction history.

4\. Transactions are stored and displayed when requested.

5\. The program exits when the user selects "Exit".



**Result**



The project successfully demonstrates a ATM simulation with authentication, transaction management, and basic banking operations implemented using Python.
